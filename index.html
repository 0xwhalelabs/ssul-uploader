친구가 읽어주는 이야기 업로더

YouTube 채널 「친구가 읽어주는 이야기」의 운영자가 쓰는 개인 업로드 도구예요.

무엇을 하나요

채널 운영자가 직접 만든 쇼츠 영상을 운영자 본인의 YouTube 채널에 올려요. 영상 파일, 제목, 설명, 태그, 썸네일을 YouTube API 서비스로 보내요. 다른 사람의 계정이나 채널에는 쓰지 않고, 외부 사용자에게 제공하지 않아요.

What this is

A private tool used only by the owner of the YouTube channel “친구가 읽어주는 이야기” to upload the owner's own short videos (video file, title, description, tags and thumbnail) to the owner's own channel through the YouTube API Services. It is not offered to any other users.
