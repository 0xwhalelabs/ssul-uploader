SSUL 업로더

한 사람의 운영자가 자기 YouTube 채널들에 자기 영상을 올릴 때 쓰는 개인 업로드 도구예요.

무엇을 하나요

운영자가 직접 만든 영상을 운영자 본인의 YouTube 채널에 비공개로 올려요. 영상 파일, 제목, 설명, 태그, 썸네일, 자막을 YouTube API 서비스로 보내요. 공개 여부는 운영자가 YouTube 스튜디오에서 직접 정해요. 다른 사람의 계정이나 채널에는 쓰지 않고, 외부 사용자에게 제공하지 않아요.

What this is

A private tool used only by one channel owner to upload the owner's own videos (video file, title, description, tags, thumbnail and captions) as private videos to the owner's own YouTube channels through the YouTube API Services. The owner decides visibility in YouTube Studio. It is not offered to any other users.
